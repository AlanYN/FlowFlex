## 一、页面级交互需求

### P1-01：文档列表页（/documents/list）

| ID | 交互需求 | 验收标准 |
|----|---------|---------|
| IR-L-01 | 页面整体布局 | 顶部操作栏（搜索 + 筛选 + 排序 + 新建按钮）+ 卡片网格区 + 底部分页，三段式垂直布局 |
| IR-L-02 | 卡片网格 | 响应式，宽屏 4 列，中屏 3 列，窄屏 2 列；卡片等高，圆角 8px，带轻阴影 |
| IR-L-03 | 卡片内容 | 顶部：文档类型图标（Sheet/Doc/Slide 各有专属 SVG 色彩图标）；中部：文档标题（最多 2 行，超出省略）；底部：修改时间 + 创建人头像 |
| IR-L-04 | 卡片悬停态 | 背景色浅提升，右上角出现「⋯ 更多」操作按钮，过渡时间 150ms |
| IR-L-05 | 操作菜单 | 点击「⋯」弹出 Dropdown：重命名、删除（红色高亮）；点击空白关闭 |
| IR-L-06 | 删除确认 | Element Plus `ElMessageBox.confirm`，标题「确认删除」，内容「删除后不可恢复，确认继续？」，确认按钮为危险色 |
| IR-L-07 | 搜索框 | placeholder「搜索文档名称…」，输入后 300ms debounce 触发查询，清空时重置结果 |
| IR-L-08 | 类型筛选 | `el-radio-group` button 形式，选项：全部 / 电子表格 / 文档 / 演示；切换立即查询 |
| IR-L-09 | 排序选择 | `el-select`，选项：最近修改（默认）/ 创建时间 / 名称；切换立即查询 |
| IR-L-10 | 空状态 | 无文档时展示居中插图 + 文案「还没有文档，点击「+ 新建文档」开始创建」+ 新建按钮 |
| IR-L-11 | 加载状态 | 初始加载时卡片区展示 Skeleton 占位（4 个同等尺寸灰色卡片）；搜索时顶部出现加载条 |
| IR-L-12 | 分页 | `el-pagination` 布局 `prev, pager, next, total`，每页 20 条；切换页码时滚动到页面顶部 |

### P1-02：新建文档弹窗（CreateDocumentDialog）

| ID | 交互需求 | 验收标准 |
|----|---------|---------|
| IR-C-01 | 弹窗触发 | 点击「+ 新建文档」按钮，`el-dialog` 宽度 480px，居中展示 |
| IR-C-02 | 文档名称输入 | `el-input`，autofocus，placeholder「请输入文档名称」，最大长度 200 字符 |
| IR-C-03 | 类型选择 | 三个大图标卡片（Sheet / Doc / Slide），横排，点击选中后边框高亮（primary 色）；默认选中 Sheet |
| IR-C-04 | 类型图标样式 | Sheet：绿色表格图标；Doc：蓝色文档图标；Slide：橙色演示图标；配图标名称文字说明 |
| IR-C-05 | 表单验证 | 名称为空点确认时，输入框下方红色提示「请输入文档名称」，弹窗不关闭 |
| IR-C-06 | 确认按钮状态 | 提交过程中按钮 loading 状态，防止重复点击 |
| IR-C-07 | 取消/关闭 | 点击取消或 × 关闭弹窗，清空表单 |
| IR-C-08 | 创建成功 | 关闭弹窗，跳转至编辑器页；**不**在列表页显示 toast，由编辑器页接管状态 |

### P1-03：文档编辑器页（/documents/:unitId/edit）

| ID | 交互需求 | 验收标准 |
|----|---------|---------|
| IR-E-01 | 顶栏布局 | 高度 56px，三区：左（返回箭头 + 文档标题）、中（空白弹性填充）、右（协同头像 + 保存按钮） |
| IR-E-02 | 返回按钮 | 点击返回至 `/documents/list`；若有未保存变更先弹确认对话框 |
| IR-E-03 | 标题行内编辑 | 默认 `<span>` 展示；点击后变为 `<input>`，失焦时保存并切回 span；最大长度 200，不允许空标题（自动还原） |
| IR-E-04 | 协同头像 | 头像组（`el-avatar-group` 或自定义），最多展示 5 个；超出数量显示 `+N`；hover 展示用户名 tooltip |
| IR-E-05 | 保存按钮 | `el-button type="primary"`，文案「保存」；保存中 loading，保存成功后 1s 内显示 `✓ 已保存` 再恢复；保存失败红色提示 |
| IR-E-06 | Ctrl+S | 全局 keydown 监听，触发与按钮保存相同逻辑 |
| IR-E-07 | 编辑器容器 | 占满顶栏以下所有高度，`height: calc(100vh - 56px)`，宽度 100%；不得有内外边距导致编辑器尺寸计算错误 |
| IR-E-08 | 加载状态 | 编辑器初始化期间（数据加载中）展示全屏加载 spinner，加载完成后隐藏 |
| IR-E-09 | 离开确认 | `onBeforeRouteLeave` 守卫；有未保存变更时弹 `ElMessageBox.confirm`，选项：「保存并离开」/ 「不保存离开」/ 「取消」 |
| IR-E-10 | 编辑器语言 | 统一使用简体中文（`LocaleType.ZH_CN`） |

## 二、微交互规范

| 场景 | 规范 |
|------|------|
| 卡片悬停 | transition: box-shadow 150ms ease, background-color 150ms ease |
| 弹窗打开 | Element Plus 默认动画，无需自定义 |
| 操作菜单弹出 | fade 150ms |
| 头像 tooltip | delay 300ms 后显示，鼠标离开立即隐藏 |
| 保存成功反馈 | 按钮文案从「保存」→「✓ 已保存」，1000ms 后恢复，无额外 toast |
| 错误提示 | `ElMessage.error(msg)`，持续 3s |
