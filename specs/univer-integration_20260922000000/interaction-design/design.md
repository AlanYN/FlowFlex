## 一、Design Tokens

沿用 FlowFlex 现有 Element Plus 主题色，不引入新色系。

### 颜色

| Token | 值 | 用途 |
|-------|-----|------|
| `--el-color-primary` | #409EFF（继承） | 选中态、主按钮、标题高亮 |
| `--doc-type-sheet` | #10B981（绿） | Sheet 类型图标色 |
| `--doc-type-doc` | #3B82F6（蓝） | Doc 类型图标色 |
| `--doc-type-slide` | #F59E0B（橙） | Slide 类型图标色 |
| `--card-bg` | #FFFFFF | 卡片背景 |
| `--card-bg-hover` | #F5F7FA | 卡片悬停背景 |
| `--card-shadow` | 0 1px 4px rgba(0,0,0,.08) | 卡片正常阴影 |
| `--card-shadow-hover` | 0 4px 12px rgba(0,0,0,.12) | 卡片悬停阴影 |
| `--toolbar-bg` | #FFFFFF | 编辑器顶栏背景 |
| `--toolbar-border` | #E4E7ED | 顶栏底边线 |

### 字体

| Token | 值 | 用途 |
|-------|-----|------|
| `--doc-title-size` | 14px | 卡片标题 |
| `--doc-meta-size` | 12px | 卡片时间/作者 |
| `--editor-title-size` | 16px | 编辑器顶栏文档标题 |
| `--toolbar-height` | 56px | 编辑器顶栏高度（固定值） |

### 圆角与间距

| Token | 值 | 用途 |
|-------|-----|------|
| `--card-radius` | 8px | 卡片圆角 |
| `--card-padding` | 16px | 卡片内边距 |
| `--grid-gap` | 16px | 卡片网格间距 |
| `--page-padding` | 24px | 页面水平内边距 |
| `--type-card-radius` | 8px | 新建弹窗类型卡片圆角 |

## 二、组件规范

### 2.1 文档卡片（DocumentCard）

```
┌─────────────────────────────────┐  ← border-radius: 8px
│  ┌──┐  文档标题（最多2行）        │
│  │🟩│  副标题文字...             │  ← 类型图标 40×40px，左对齐
│  └──┘                           │
│  ─────────────────────────────  │
│  🕐 3小时前    ● 张三  [⋯]      │  ← 底部 meta，⋯ 按钮仅 hover 可见
└─────────────────────────────────┘
```

**Props：**
```typescript
interface DocumentCardProps {
  id: string
  unitId: string
  title: string
  docType: 'Sheet' | 'Doc' | 'Slide'
  modifyDate: string
  createBy: string
}
```

**Emits：** `click`、`rename`、`delete`

```
│  └──────────────────────────────────┘   │
│                                          │

```

## 四、关键交互约定

| 约定 | 说明 |
|------|------|
| 导航守卫 | 编辑器页离开时，`hasUnsaved` 为 true 则拦截，弹三选确认框 |
| 标题空值保护 | 行内编辑失焦时，若 title 为空则自动还原上一次合法值，不保存 |
| 操作日志异步化 | `logMutation` 调用 `addOperationLog`，使用 fire-and-forget 模式，失败静默不影响编辑 |
| 协同头像排序 | 最近活跃的用户排在最前，超出 5 个时折叠显示 `+N` |
| 编辑器高度约束 | 顶栏高度 56px 为固定值，编辑器容器高度必须用 `calc(100vh - 56px)` 计算，禁止 `height: auto` |
| Univer 语言包 | 统一使用 ZH_CN，在 `onMounted` 内初始化时传入 |
