# Requirements — Univer 在线文档管理功能

> 阶段：requirements-analysis  
> 模块：univer-integration  
> 创建日期：2026-09-22

---

## 一、背景与目标

FlowFlex 当前缺乏在线文档编辑能力。引入 Univer（Apache 2.0 开源框架）后，用户可以直接在平台内创建和编辑类 Excel 电子表格、类 Word 富文本文档、类 PPT 演示文稿，并支持多人实时协同编辑，数据存储在 FlowFlex 后端。

**核心价值：** 在不离开 FlowFlex 的情况下，完成文档的创建、编辑、存储和多人协作。

---

## 二、用户故事与验收标准

### US-01：文档列表管理

**As a** FlowFlex 用户  
**I want to** 在独立的「文档管理」菜单下查看所有文档  
**So that** 我可以快速找到、创建或删除文档

**验收标准（AC）：**

| ID | 条件 | 预期结果 |
|----|------|---------|
| AC-01-1 | 用户进入 `/documents/list` | 以卡片形式展示当前租户下的所有文档，显示标题、类型 Tag、创建人、最近修改时间 |
| AC-01-2 | 列表支持关键词搜索 | 输入关键词后实时过滤，仅展示标题匹配的文档 |
| AC-01-3 | 列表支持按类型筛选 | 可选 All / Sheet / Doc / Slide，切换后列表刷新 |
| AC-01-4 | 列表支持排序 | 可按「最近修改」「创建时间」「名称」排序，默认按最近修改降序 |
| AC-01-5 | 列表分页 | 每页 20 条，底部显示分页组件 |
| AC-01-6 | 右键/操作菜单 | 每张卡片有「重命名」「删除」操作；删除需二次确认 |

---

### US-02：新建文档

**As a** FlowFlex 用户  
**I want to** 通过弹窗快速新建一个文档  
**So that** 我可以立即开始编辑

**验收标准（AC）：**

| ID | 条件 | 预期结果 |
|----|------|---------|
| AC-02-1 | 点击「+ 新建文档」按钮 | 弹出新建弹窗，包含「文档名称」输入框和「文档类型」三选一（电子表格/文档/演示） |
| AC-02-2 | 未填写文档名称直接确认 | 提示「请输入文档名称」，不关闭弹窗 |
| AC-02-3 | 填写名称并选择类型后确认 | 后端创建空白快照，前端跳转至编辑器页 `/documents/:unitId/edit` |
| AC-02-4 | 默认文档类型 | 默认选中「电子表格（Sheet）」 |

---

### US-03：编辑电子表格（Sheet）

**As a** FlowFlex 用户  
**I want to** 打开一个 Sheet 文档并进行编辑  
**So that** 我可以在线处理表格数据

**验收标准（AC）：**

| ID | 条件 | 预期结果 |
|----|------|---------|
| AC-03-1 | 从列表点击 Sheet 文档卡片 | 跳转至编辑器页，Univer Sheets 编辑器加载完成 |
| AC-03-2 | 编辑器功能完整 | 支持公式、条件格式、数据验证、筛选/排序、查找替换、超链接、绘图/图片、数字格式、批注、便签、表格 |
| AC-03-3 | 点击「保存」按钮 | 调用 `getWorkbookData()` 获取完整数据，POST 到后端 `/ow/document-snapshots/v1/:unitId/save` |
| AC-03-4 | `Ctrl+S` 快捷键 | 触发保存，效果同 AC-03-3 |
| AC-03-5 | 文档标题行内编辑 | 点击标题可直接修改，失焦后自动保存标题（仅更新 title 字段） |
| AC-03-6 | 离开页面前有未保存变更 | 弹出确认弹窗「是否保存后离开？」 |

**As a** FlowFlex 用户  
**I want to** 打开一个 Slide 文档并进行编辑  
**So that** 我可以在线制作演示文稿

**验收标准（AC）：**

| ID | 条件 | 预期结果 |
|----|------|---------|

| AC-05-2 | 保存 | 同 AC-03-3 |

### US-06：操作日志记录

**As a** FlowFlex 管理员  
**I want to** 查看每个文档的操作历史  
**So that** 我可以追溯谁在什么时候做了什么修改

**验收标准（AC）：**

| ID | 条件 | 预期结果 |
|----|------|---------|
| AC-06-1 | 用户在编辑器中做任何编辑操作 | 前端监听 `onCommandExecuted`（MUTATION 类型），异步 POST 操作日志到后端，不阻塞编辑 |
| AC-06-2 | 日志字段 | 记录：unitId、操作用户ID、用户名、操作时间戳（ms）、MutationId、操作参数 JSON |
| AC-06-3 | 后端日志查询 | 提供按 unitId 查询日志的 API，支持时间范围和用户过滤 |

---

### US-07：多人实时协同编辑

**As a** FlowFlex 用户  
**I want to** 与他人同时编辑同一文档  
**So that** 我们可以实时协作

**验收标准（AC）：**

| ID | 条件 | 预期结果 |
|----|------|---------|
| AC-07-1 | 两个用户同时打开同一文档 | 顶栏显示协同者头像列表 |
| AC-07-2 | 用户 A 编辑后 | 用户 B 的编辑器在 1 秒内同步显示 A 的变更 |
| AC-07-3 | 并发冲突（乐观锁） | 后端校验 `baseRev`，冲突时返回 `cs_rej`，前端自动重试 |
| AC-07-4 | 协同者离开 | 顶栏头像列表移除该用户 |

## 三、非功能性需求

| 类别 | 要求 |
|------|------|
| 兼容性 | 不破坏现有 FlowFlex 功能和页面样式 |
| 多租户 | 文档数据严格按 `tenant_id + app_code` 隔离 |
| 安全 | 访问需 JWT 认证，操作需 `DOCUMENTS` 权限码 |
| 性能 | `workbookData` 不放入 Vue 响应式系统；编辑器容器需明确高度 |
| 样式 | Tailwind base reset 不破坏 Univer 内部 UI（`important: '#app'` 方案） |
| 许可证 | Univer Apache 2.0，商业使用合规，分发时保留 LICENSE |
