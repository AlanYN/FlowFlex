# Tour Guide 内容规划

## 1. Stage 详情页 Tour Guide

| Step | 锚点位置               | Tooltip 内容                                                                                                                    | 条件                           |
| ---- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ |
| 1    | Case 标题 / Stage 标题 | 你被分配负责 {{case_name}} 的 {{stage_name}} 阶段。下面是你需要完成的所有任务。                                                 | 始终显示                       |
| 2    | Stage 进度条           | 这是整个流程的进度。高亮的是你当前负责的阶段。                                                                                  | 始终显示                       |
| 3    | Fields 区域            | 填写这些信息字段。内容会自动保存，无需额外提交。                                                                                | 仅当 Stage 包含 fields         |
| 4    | Checklist 区域         | 这是任务清单。每项任务除了打勾确认外，还可以添加备注（Notes）和上传附件（Attachment）作为完成凭证。全部勾完后自动标记为已完成。 | 仅当 Stage 包含 checklist      |
| 5    | Questionnaire 区域     | 这是信息收集表单。按各部分填写，带 \* 为必填。全部完成后点提交。                                                                | 仅当 Stage 包含 questionnaires |
| 6    | Quick Link 区域        | 点击此链接跳转到外部系统完成操作，完成后回到本页继续。                                                                          | 仅当 Stage 包含 quick link     |
| 7    | File Upload 区域       | 将文件拖拽到此区域或点击上传，文件自动关联到当前阶段。                                                                          | 仅当 Stage 包含 files          |
| 8    | 推进按钮               | 以上所有必填项完成后，点击此按钮推进到下一阶段。推进后本阶段锁定。                                                              | 始终显示                       |

---

## 2. Checklist 区域 Tour Guide

| Step | 锚点                    | 标题     | 内容                                                           |
| ---- | ----------------------- | -------- | -------------------------------------------------------------- |
| 1    | Checklist 标题          | 任务清单 | 这是一个任务清单，包含 {{task_count}} 项任务。你需要逐项完成。 |
| 2    | 第一个 Task 勾选框      | 勾选完成 | 确认任务完成后，点击勾选框标记为已完成。                       |
| 3    | Task 的 Notes 按钮      | 添加备注 | 点击这里为任务添加 Notes（备注），记录操作说明或补充信息。     |
| 4    | Task 的 Attachment 按钮 | 上传附件 | 如需提供佐证材料，点击这里上传 Attachment（附件）。            |
| 5    | 完成进度                | 完成进度 | 所有任务勾选完成后，清单自动标记为已完成。进度实时更新。       |

---

## 3. Questionnaire 区域 Tour Guide

| Step | 锚点               | 内容                                                |
| ---- | ------------------ | --------------------------------------------------- |
| 1    | Questionnaire 标题 | 这是一份信息收集表单，共 {{section_count}} 个部分。 |
| 2    | Section 标签       | 点击各部分标签切换填写。                            |
| 3    | Required 标记      | 带 \* 的问题为必填，未填完无法提交。                |
| 4    | 提交按钮           | 全部填写完成后点击提交。提交后内容将锁定。          |
